# 6. قائمة الشاشات (Screen Inventory)

> 46 شاشة/نافذة مرتبة بالموديول. «نافذة» = Dialog فوق شاشة. كل الشاشات RTL وتدعم Dark/Light واختصارات لوحة المفاتيح المذكورة في §6.13.

## 6.1 الدخول والنظام

| # | الشاشة | العناصر الأساسية |
|---|---|---|
| S01 | تسجيل الدخول | اسم مستخدم، كلمة مرور، رسائل خطأ عامة (بدون تحديد أيهما خطأ)، عدّاد محاولات |
| S02 | قفل الشاشة (خمول) | صورة/اسم المستخدم الحالي + كلمة المرور فقط للعودة؛ زر «تبديل مستخدم» |
| S03 | الشاشة الرئيسية / الإطار العام | قائمة جانبية بالموديولات حسب الصلاحية، شريط علوي (المستخدم، الوردية الحالية، جرس التنبيهات بعدّاد، مفتاح Dark/Light)، منطقة المحتوى |
| S04 | مركز التنبيهات | قوائم مبوبة: أقساط اليوم/متأخرات/مخزون منخفض/راكد/حجوزات تنتهي/نسخ احتياطي — كل عنصر ينقل لشاشته |

## 6.2 لوحة التحكم والتقارير

| # | الشاشة | ملاحظات |
|---|---|---|
| S05 | Dashboard | البطاقات والرسوم في الوثيقة 08 §3 |
| S06 | مركز التقارير | شبكة كل التقارير (18 تقريرًا) حسب الصلاحية |
| S07 | عارض التقرير العام | معايير أعلى + جدول نتائج + إجماليات + أزرار طباعة/PDF/Excel |

## 6.3 الكتالوج والمخزون

| # | الشاشة | العناصر |
|---|---|---|
| S08 | قائمة الموتوسيكلات | جدول بفلاتر (حالة/ماركة/موديل/لون/جديد-مستعمل) + بحث فوري شاسيه/موتور/كود + تلوين صفوف بالحالة + شارة «راكد» |
| S09 | بطاقة موتوسيكل (تفاصيل) | كل بيانات الوحدة، التكلفة التفصيلية (حسب الصلاحية)، الجدول الزمني الكامل للحركة، أزرار سياقية بالحالة: بيع/حجز/تعديل سعر/إضافة مصروف/تحويل حالة/مرتجع للمورد |
| S10 | إضافة/تعديل موتوسيكل | نموذج بالحقول + تحقق فوري من تفرد الشاسيه والموتور |
| S11 | نافذة إضافة مصروف على وحدة | نوع، مبلغ، هل يُصرف نقدًا الآن (يولد سند صرف) |
| S12 | قائمة الأصناف العامة | جدول بكمية وحد الطلب مع تظليل المنخفض/النافد، بحث بالاسم/الباركود |
| S13 | إضافة/تعديل صنف | اسم، تصنيف، باركود، وحدة، تكلفة، سعر بيع، حد إعادة الطلب |
| S14 | إدارة الكتالوج | تبويبات: ماركات/موديلات/ألوان/تصنيفات (CRUD بسيط) |
| S15 | الجرد | إنشاء جرد، إدخال العد، شاشة الفروق، اعتماد وطباعة محضر جرد |
| S16 | رصيد افتتاحي (معالج أول تشغيل) | خطوات: بيانات المعرض → مستخدمون → طرق دفع وأرصدتها → وحدات وأصناف افتتاحية → أرصدة عملاء/موردين |

## 6.4 المشتريات والموردون

| # | الشاشة | العناصر |
|---|---|---|
| S17 | قائمة فواتير الشراء | فلاتر مورد/فترة/حالة + إجماليات |
| S18 | فاتورة شراء جديدة | رأس (مورد/تاريخ/سداد) + شبكة بنود بإضافة سريعة للوحدات (صف لكل وحدة بشاسيه وموتور) + قسم مصاريف بتوزيعها + قسم الدفع |
| S19 | عرض فاتورة شراء | للقراءة + أزرار: مرتجع، سند صرف للمتبقي، إلغاء (بشروط) |
| S20 | مرتجع شراء | اختيار البنود من الأصل + طريقة الرد |
| S21 | قائمة الموردين + بطاقة مورد | البطاقة: بيانات + رصيد + كشف حساب + أزرار سند صرف/فاتورة جديدة |

## 6.5 العملاء

| # | الشاشة | العناصر |
|---|---|---|
| S22 | قائمة العملاء | بحث اسم/موبايل/رقم قومي، عمود رصيد ومتأخرات، فلتر «عليه متأخرات» |
| S23 | بطاقة عميل | بيانات + مندوبه + رصيد + نقاط + تبويبات: فواتيره/عقود تقسيطه/حجوزاته/كشف حساب/ملاحظات |
| S24 | إضافة/تعديل عميل | الحقول + مندوب البيع + تحقق تفرد الرقم القومي |
| S25 | نافذة نقاط يدوية | إضافة/خصم نقاط بسبب إلزامي |
| S26 | إدارة الضامنين | قائمة + نموذج (يُفتح غالبًا كنافذة من عقد التقسيط) |
| S27 | إدارة مندوبي البيع | CRUD بسيط |

## 6.6 البيع POS

| # | الشاشة | العناصر |
|---|---|---|
| S28 | **شاشة POS الرئيسية** | ثلاث مناطق: (يمين) بحث فوري + نتائج ببطاقات كبيرة تلمس بالماوس؛ (وسط) السلة ببنود وخصومات لكل بند؛ (يسار/أسفل) الإجماليات + العميل + أزرار كبيرة: دفع F9 / حجز F7 / تعليق فاتورة F6 / استرجاع معلقة. خط كبير وتباين عالٍ |
| S29 | نافذة الدفع | توزيع على طرق دفع متعددة، المدفوع/الباقي، نوع البيع (نقدي/آجل/تقسيط)، زر «دفع وطباعة» |
| S30 | نافذة اختيار/إنشاء عميل سريع | بحث + إنشاء مختصر (اسم/موبايل) مع إكمال البيانات لاحقًا إلا في الآجل/التقسيط |
| S31 | نافذة موافقة المدير | سبب الطلب + قيمة + حقلا اعتماد (مستخدم/كلمة مرور) |
| S32 | نافذة استبدال مستعمل | بيانات الوحدة الداخلة + سعر التقييم + المعتمِد |
| S33 | قائمة فواتير البيع | فلاتر نوع/فترة/عميل/مستخدم/حالة + بحث برقم |
| S34 | عرض فاتورة بيع | كاملة + الربح (حسب صلاحية) + أزرار: طباعة، تحصيل، مرتجع، إلغاء (بشروط) |
| S35 | مرتجع بيع | اختيار بنود من الأصل + رسوم إرجاع + طريقة الرد |
| S36 | الحجوزات | قائمة بحالة ومدة متبقية ملونة + أزرار: تحويل لفاتورة/تمديد/إلغاء بقرار عربون |

## 6.7 التقسيط

| # | الشاشة | العناصر |
|---|---|---|
| S37 | نافذة شروط التقسيط (ضمن البيع) | مقدم/نسبة/شهور/يوم استحقاق/أول قسط/ضامن + **معاينة الجدول الحية** قبل الحفظ |
| S38 | قائمة عقود التقسيط | فلاتر حالة/تعثر + أعمدة: المحصل/المتبقي/عدد المتأخر |
| S39 | بطاقة عقد | بيانات + الضامن + جدول الأقساط ملونًا (مدفوع/جزئي/مستحق/متأخر) + سجل التحصيلات + أزرار: تحصيل/سداد مبكر/إعادة جدولة/طباعة عقد وجدول |
| S40 | شاشة تحصيل قسط | بحث عميل/عقد أو من قائمة اليوم، إدخال المبلغ ومعاينة التوزيع على الأقساط، طرق الدفع، «تحصيل وطباعة إيصال» |
| S41 | المتأخرات | قائمة بأيام التأخير والقيمة وبيانات الاتصال بالعميل والضامن + تسجيل ملاحظة متابعة |

## 6.8 المالية والخزنة

| # | الشاشة | العناصر |
|---|---|---|
| S42 | سند قبض / سند صرف | نوع الطرف، الغرض، المبلغ، طريقة الدفع، البيان، طباعة فورية |
| S43 | المصروفات | قائمة + تسجيل مصروف (فئة/مبلغ/طريقة/بيان) + إدارة الفئات |
| S44 | طرق الدفع | الأرصدة الحالية ببطاقات + كشف حساب لكل طريقة + مستند تحويل بين طريقتين + مطابقة رصيد |
| S45 | الوردية | ثلاث حالات للشاشة: فتح (عد افتتاحي) / أثناء (ملخص ورديتي) / قفل (متوقع/معدود بمساعد فئات العملة/فرق واعتماد) + طباعة Z + سجل الورديات السابقة |

## 6.9 الإدارة والنظام

| # | الشاشة | العناصر |
|---|---|---|
| S46 | إدارة المستخدمين والأدوار | مستخدمون CRUD + شاشة دور بمصفوفة صلاحيات Checkboxes + سجل جلسات |
| S47 | الإعدادات | تبويبات: بيانات المعرض والشعار / المالية (ضريبة، حدود خصم، سياسة عربون وتقسيط) / الطباعة (طابعة حراري وA4، نص تذييل) / الترقيم / التنبيهات (أيام الركود، حد المخزون) / النسخ الاحتياطي (جدولة واحتفاظ) / الواجهة (ثيم، دقائق قفل الخمول) |
| S48 | النسخ الاحتياطي | قائمة النسخ مع الحجم والتاريخ ونتيجة الفحص + أزرار: نسخة الآن / نسخة على فلاشة / معالج الاستعادة (Owner) |
| S49 | سجل التدقيق Audit | فلاتر مستخدم/نوع/فترة/كيان + عرض القيمة قبل/بعد |

## 6.13 اختصارات لوحة المفاتيح (شاشة POS)

| المفتاح | الوظيفة |
|---|---|
| F2 | تركيز البحث |
| F4 | اختيار عميل |
| F6 / Shift+F6 | تعليق فاتورة / استرجاع معلقة |
| F7 | حجز الوحدة المحددة |
| F8 | خصم على الفاتورة |
| F9 | الدفع |
| F12 | طباعة آخر مستند |
| Delete | حذف بند من السلة |
| Ctrl+L | قفل الشاشة فورًا |

> ملاحظات UX إلزامية: أزرار الإجراء الرئيسي كبيرة (≥ 44px)، رسائل الخطأ بالعربية وبصياغة «ماذا أفعل الآن»، تأكيد صوتي/بصري عند نجاح الحفظ والطباعة، وعدم استخدام الأحمر إلا للخطأ الفعلي (المتأخرات/العجز).
