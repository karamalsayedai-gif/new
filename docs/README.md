## اصطلاحات عامة

- العملة الافتراضية: الجنيه المصري (EGP)، وكل المبالغ تُخزَّن كأعداد صحيحة بالقرش (Integer piasters) لتجنّب أخطاء الفاصلة العشرية.
- التواريخ تُخزَّن بصيغة ISO-8601 بتوقيت الجهاز المحلي.
- كلمة «موتوسيكل/وحدة» تعني وحدة فريدة لها شاسيه وموتور، وكلمة «صنف عام» تعني منتجًا كميًا (إكسسوارات، زيوت…).
